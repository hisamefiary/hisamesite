再生




読み込んだテキストは以下に格納されています
@ time text voice delay

コマンドを入力して再生を押すと
時間通りにテキストを表示し、音声を読み上げます

音声は同時に複数の読み上げ命令が入った場合、古いものが中断されます(遅延対策)
テキスト入力モードによって挙動が変わります
localStorageを利用してる為、入力されたデータが次開いても残るようになっています
前半と後半で湧かれているコンテンツを考慮して一時的に入力場所のみ保存が反映されません
ウェブサイト上で完結することを求めているため、機能はそれほどありませんがよろしければどうぞ

スプシ起動
カテゴリ time text voice delay
正規表現 (-?[0-9]+:[0-9]+|-?[0-9]+) ([^\t]*?) ([^\t]*?) (-?[0-9]+:[0-9]+|-?[0-9]+)?
サンプル 10 クレメンシー 回復 3
0:15 ソルトアース 引き寄せ 0:04
実際の挙動 7秒に「回復」と発言(10-3)
7秒から10秒まで「クレメンシー」と「回復」のテキスト表示(10-3)
11秒に「引き寄せ」と発言(15-4)
11秒から15秒まで「ソルトアース」と「引き寄せ」のテキスト表示(15-4)
補足説明 [A秒]に来る[アクション名B]に対して[テキストC]を[D秒前]に読み上げる形式です
[A秒]のみ必須、他は任意です
サンプルの様なスプレッドシートを作成し、該当4列xN行をコピペすると読み込まれます
区切り文字の観点上、直接コピペ以外の稼働は保証できません
(多分エクセルやテキストファイルでも可能だと思いますが…)
時間表記はどちらでも可能です(分:秒or秒)
すぺすぺもどき
サンプル 正規表現
区切り(必須) (改行) [\r\n]
時間(必須) time="010" time="([0-9]+)"
テキスト text="クレメンシー" text="([^"]+)"
読み上げ notice="回復" notice="([^"]+)"
サンプル <a time="010" text="クレメンシー" sync="ナイトの「クレメンシー」" notice="回復" />
<a time="015" text="ソルトアース" sync="暗黒騎士の「ソルトアース」" notice="引き寄せ" sync-interval="10" />
実際の挙動 0秒に「回復」と発言
10秒まで「クレメンシー」と「回復」のテキスト表示
10秒に「引き寄せ」と発言
15秒まで「ソルトアース」と「引き寄せ」のテキスト表示
補足説明 中身の挙動を知らず推測で書いているため、本物とは挙動が大分違う可能性があります
そもそもすべてが正しく動くかの保証もありませんが、スペスペをスプシ用に変換できる為、参考資料として置いておきます
ひとつ前の指定したtime時点→noticeが読み上げ、text,noticeの文字が表示
自身の指定した→text,noticeの文字が消える
の2要素のみとなっています
